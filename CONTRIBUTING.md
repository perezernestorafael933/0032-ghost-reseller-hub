# 🤝 GUÍA DE CONTRIBUCIÓN Y DESARROLLO SDD
### Proyecto: `0032-ghost-reseller-hub`

1. **Metodología Oficial:** Spec-Driven Development (SDD) vía `.specify/`.
2. **Tipado y Calidad:** Todo código en `src/` o módulos core debe emplear tipado estricto (`typing`) y manejo robusto de excepciones.
3. **Validación Determinista:** Cada Pull Request debe pasar el 100% de la suite de pruebas (`pytest tests/`).
4. **Optimización de Minutos:** Emplear `[skip render]` en commits de solo documentación.
